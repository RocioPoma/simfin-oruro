# SimFin Oruro

Programa de simulación y diagnóstico financiero para empresas y personas del entorno orureño.
Proyecto socioformativo de Finanzas Empresariales I, Universidad Privada Domingo Savio, sede Oruro.

## Qué hace
- Perfiles: Producción, Comercio, Servicios, Construcción, Asalariado y Persona natural.
- Carga de estados financieros en imagen, PDF, Word (.docx) y Excel (.xlsx, .xls, .csv).
- Ratios de liquidez, actividad, endeudamiento y rentabilidad con semáforo por rubro.
- Índice de Salud Financiera (0 a 100), radar, cascada de resultados, análisis vertical y horizontal.
- Apalancamiento GAO, GAF y GAM, punto de equilibrio, DuPont y Z'' de Altman.
- Simulador de escenarios e informe en lenguaje sencillo.

## Uso
Abra `index.html` en el navegador o publíquelo con GitHub Pages (Settings → Pages → rama `main`, carpeta raíz).

Con fines educativos. No reemplaza la asesoría de un profesional.
